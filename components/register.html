Timing diagram

Each column is one clock cycle. Q changes only on the rising edge, according to the clr/ld values at that moment.

One mux per bit

Every flip-flop loads on every clock edge. What it loads is chosen by its 4×1 mux: its own q (so it keeps its value), the new data bit d, or a constant 0. The same clr/ld pair drives all three muxes, so the bits always act together.

Clear is synchronous

Setting clr does nothing on its own. The register only becomes 0 at the next rising edge, when the flip-flops capture the 0 on input i2. Between edges Q never changes, whatever clr, ld and D do.

clr = ld = 1

Input i3 is wired back to q, so asserting both controls maintains the value. Other designs give one control priority instead (for example clear wins); that only changes what is wired to i3.
