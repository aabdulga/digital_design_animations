Up Counter

A 4-bit up counter. A 4-bit load/clear register holds the count C; a +1 block adds one to C and feeds it back to the register's data input. With cnt high, every rising edge loads that incremented value. When the count reaches 15 the terminal-count line tc goes high, and the next increment wraps around to 0.

4-bit up counter

logic 0data at 1clr / cnt / clk at 1 Thick lines are 4-bit buses. Click clr or cnt to flip it.

The register's ld input is driven by cnt, so it loads C + 1 only on cycles where cnt = 1. clr forces 0000. tc = C3 · C2 · C1 · C0.

Timing diagram

Each column is one clock cycle. C updates on the rising edge; tc is combinational, so it is high during the whole time C = 15.

Register plus adder

A counter is just a register whose next value is computed from its current value. Here the logic is a +1 incrementer; swap it for −1 and you have a down counter.

Terminal count

tc is 1 only when all four bits are 1 (C = 15). It warns that the next increment wraps to 0, and it can drive the cnt input of a second counter to chain two 4-bit counters into an 8-bit one.

Why clr + cnt maintains

In this design clr and cnt both going high is not a valid command, so the register simply holds its value. The function table lists all four combinations.
