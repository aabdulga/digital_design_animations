4-to-1 Multiplexer

A multiplexer is a data selector. The two select lines S1 S0 form a binary number that picks one of the four data inputs and passes it to the output Y. Inside, each AND gate is enabled by exactly one select combination, and an OR gate collects the result.

Block view

What it does

Think of a rotary switch. The select number S1 S0 turns the switch to one input, and that input's value appears on Y. The other inputs are ignored.

The equation

Y = S1'S0'·I0 + S1'S0·I1 + S1S0'·I2 + S1S0·I3. Each product term is one AND gate; the sum is the OR gate.

Only one gate is enabled

For any select value, exactly one AND gate sees two 1s on its select inputs (outlined in teal). The other three output 0 no matter what their data input is.

Scaling up

A 2n-to-1 mux needs n select lines. An 8-to-1 mux has 8 four-input AND gates and an 8-input OR gate, or can be built from smaller muxes in a tree.
