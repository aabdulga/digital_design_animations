NOR SR Latch

Two cross-coupled NOR gates. Each gate's output feeds the other's input, so the circuit remembers. Flip S or R and watch the change propagate one gate delay at a time.

Propagation log

Stable at power-up with S = R = 0, Q = 0, Q̅ = 1. Click a switch.

Gate 1 computes Q = NOT(R OR Q̅); gate 2 computes Q̅ = NOT(S OR Q). Each step in the log is one gate delay: both gates read their inputs and update their outputs at once.

Memory from feedback

With S = R = 0 each NOR gate just inverts the other gate's output. Two inverters in a loop have two stable states, Q = 1 or Q = 0, and the loop keeps whichever one it is in. That is one stored bit.

Set and reset

A 1 on any NOR input forces its output to 0. S = 1 pulls Q̅ low, which makes Q rise; R = 1 pulls Q low, which makes Q̅ rise. Releasing the input changes nothing: the feedback holds the new state.

Why S = R = 1 is forbidden

Both outputs are forced to 0, so Q and Q̅ stop being complements. Worse, if S and R then drop together, both gates flip at the same time and keep flipping: a race that real hardware settles by whichever gate is a hair faster.
